## Key Architectural Patterns

### Frontend Patterns
- Custom hooks pattern: `useYjsProvider` for Yjs integration
- useRef to persist Yjs objects (Y.Doc, WebsocketProvider) across re-renders
- Always destroy Yjs objects in useEffect cleanup to prevent memory leaks
- Component composition: parent observes Y.Text, passes to child components via props
- Connection status UI: green (connected), yellow (connecting), red (disconnected)

### Backend Patterns
- NodeNext module resolution for backend apps
- In-memory Map<string, Y.Doc> for document persistence
- y-websocket setupWSConnection handles all Yjs sync protocol automatically
- Document room name extracted from WebSocket URL path

### Testing Approach
- **Initial blocker**: Browser testing failed due to Ralph streaming mode limitations
- **Solution**: Pivoted to automated testing with Vitest + @testing-library/react
- **Result**: 128 comprehensive tests passing across 8 test suites
- Test coverage: component rendering, bidirectional sync, real-time updates, routing, edge cases

- TypeScript JSX: Use React.ReactElement instead of JSX.Element for render functions
